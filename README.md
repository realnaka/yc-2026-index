# YC 2026 Startup Index

Interactive directory and infrastructure analysis for 833 Y Combinator companies
listed in the Winter, Spring, Summer, and Fall 2026 cohorts.

The page supports:

- search across all companies;
- filtering by cohort, industry, AI tag, and curated agent infrastructure;
- company detail drawers;
- cohort and industry charts;
- an interactive map of 49 agent infrastructure companies.

## Data

The snapshot was retrieved from the public YC Startup Directory on 2026-11-08.
Company descriptions and performance claims are company-provided unless stated
otherwise. The page is an independent research artifact and is not affiliated
with or endorsed by Y Combinator.

## Run locally

Open `index.html` directly. All application code, data, fonts, and styles are
embedded in the file.
