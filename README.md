# YC 2026 Startup Index

## ▶ [打开在线网页](https://realnaka.github.io/yc-2026-index/)

[![YC 2026 网页预览](assets/yc-2026-preview.png)](https://realnaka.github.io/yc-2026-index/)

一个可交互的 YC 2026 公司索引，覆盖 **Winter、Spring、Summer、Fall 四个批次，共 833 家公司**。

网页从“投了什么”和“为什么这样投”两个角度整理数据。它不只给公司名单，还展示行业结构、AI/agent 渗透和 Agent 基建竞争格局。

## 网页内容

| 模块 | 内容 |
|---|---|
| 总览 | 四批公司数量、10 个互斥业务主分类、AI 标签分布 |
| Agent 基建图谱 | 跨行业专题：49 家 sandbox、coding agent、CI、Agent Ops、Eval/RL 公司 |
| 公司目录 | 833 家公司全量搜索与筛选 |
| 公司详情 | 官方介绍、YC 页面、公司官网、X/Twitter 链接 |
| 数据口径 | 70% agent 数字的边界、供应商自述与人工归类说明 |

## 可以做什么

- 按批次、行业和 AI 标签筛选公司。
- 用 10 个互斥业务分类筛选全部公司，避免把宽泛的 B2B 当成分析分类。
- 搜索公司名称、一句话介绍、行业、城市和标签。
- 按 sandbox、coding agent、验证、成本、Agent Ops、Eval/RL 查看基建公司。
- 打开每家公司的官网和 X 入口。
- 点击图谱中的公司，查看完整资料。

## X/Twitter 链接口径

网页优先使用公司官方 X 账号。其次使用公司官网公开的 X 链接。再次使用 YC 公司页中的创始团队 X 账号。

|---|---:|

搜索回退会明确标记为「搜 X」，不会伪装成官方账号。

## 数据说明

- 数据快照取自 YC 官方 Startup Directory，日期为 **2026-11-08**。
- F26 仍可能继续增加公司，因此当前数量不是最终批次总数。
- 公司介绍、价格、速度、客户数和成本倍数属于公司公开自述。
- “Agent 基建精选”是本项目按产品语义人工归类的结果，不是 YC 官方分类。
- Agent 基建是跨行业专题，不是覆盖全部 833 家公司的平行主分类。
- “70% 在做 AI agent”来自第三方对 Spring 2026 的独立复核，不应外推到全年。

本项目是独立研究页面，与 Y Combinator 无隶属或背书关系。
